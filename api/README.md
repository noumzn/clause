# Clause

A customer-support assistant for Clause Shop, built with RAG (Retrieval-Augmented Generation) on a local Ollama setup.

## Project layout

| Folder       | What it holds                                         |
|--------------|-------------------------------------------------------|
| `api/`       | Python RAG backend (LangChain + Ollama)               |
| `web/`       | Frontend (coming soon)                                |
| `notebooks/` | Step-by-step learning notebooks                       |
| `playground/`| Standalone RAG scripts for trying ideas locally       |

- See [`api/README.md`](api/README.md) to run the backend.
- See [`playground/README.md`](playground/README.md) to run the RAG experiments.
